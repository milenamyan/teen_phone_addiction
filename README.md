# Teen Phone Addiction Analysis 📱

This project analyzes teenage phone usage behavior using a dataset in CSV format. It demonstrates how to work with `pandas.Series` and `pandas.DataFrame`, and applies filtering, grouping, renaming columns, pivot tables, and file export operations.

---

## 🛠 Features

- Create and manipulate `Series` objects
- Load and clean a real-world CSV dataset
- Rename columns for clarity
- Slice and filter data using `iloc`, `loc`
- Add derived columns like Date of Birth (`DOB`)
- Group data by age and analyze usage
- Generate pivot tables for aggregate views
- Save cleaned data to CSV and Parquet formats

---

## 📁 Files

- `analaize_data.py` – The main script for analysis
- `teen_phone_addiction_dataset.csv` – Input dataset
- `new_data` – Cleaned data saved as CSV
- `new_data2` – Cleaned data saved as Parquet (more efficient)
